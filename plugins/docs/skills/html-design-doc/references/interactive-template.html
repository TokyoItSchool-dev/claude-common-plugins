1. この見本について

NOTE

本文はすべてサンプルであり、記載された数値・社数・期間に意味はない。実際の文書を書くときはこの節ごと差し替える。金額は「〇〇万円」のままにしてあり、実在の見積りではない。

この見本は、手順Dで使うコンポーネントを1つずつ実際に描画したものである。第2章に各コンポーネントの見本を、第3章に3つのレイアウトパターンの骨格を置く。レイアウトパターンは文書ごとに1つだけを選ぶ。同じ文書に複数を同居させない。

WARN

この文書の <script> は2本だけである。1本目が本ファイル先頭のインタラクション用、2本目が末尾の目次開閉用で、いずれも配布用の packed 出力ではインラインになる。図はすべてSVGを直接記述しており、外部の画像・CSS・フォントを参照しない。

3. レイアウトパターン

次の3つから1つだけを選び、文書全体をその骨格で書く。ここでは比較のために3つを並べているが、実際の文書では1つだけを残して他は削除する。

パターン向いている資料読み手の動線弱点
dashboard全体像を1画面で見せる提案書上部のタブで面を切り替える面をまたぐ比較がしにくい
narrative前提から結論まで順に読ませる説明書上から下へ読み進める縦に長く全体像がつかみにくい
flow1つのプロセスを軸にした資料ノードを選んで詳細を見る図に乗らない話題の置き場所が乏しい

付録

A. 検証項目

項目確認方法
JS無効時の可読性ブラウザでJavaScriptを切り、全パネル・全シナリオ・全ノードが読めること
印刷時の展開印刷プレビューで操作要素が消え、全パネルとアコーディオンが展開されること
外部参照ゼロプロトコル指定・外部CSSの取り込み・CSSの外部アセット指定・要素の外部ファイル指定をグレップし、ルールを説明したコメント以外に出現しないこと（検査は pack_doc.py が行う）
スクリプト本数スクリプト要素が2本のみであること
参照の解決すべての aria-controls・aria-labelledby・ページ内リンクの参照先が、実在する id であること
タグ整合パーサで開始タグと終了タグの対応を確認すること
