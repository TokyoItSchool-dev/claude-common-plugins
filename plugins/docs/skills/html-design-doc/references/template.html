サンプル設計書

最終更新: 2026-07-31 ／ 作成: html-design-doc スキル

1. 概要

本ドキュメントは html-design-doc スキルが生成するスタンドアロンHTMLの見本である。左側の目次は画面に固定され、本文は読みやすい幅に収まる。見出し・表・コード・注釈・図の書き方をこのファイル1つで確認できる。

NOTE

このテンプレートは単一ファイルで完結する。外部参照は Mermaid の CDN スクリプト1本のみで、外部CSSやフォントは読み込まない。

  • 対象は設計書・説明書・俯瞰資料などの読み物ドキュメント
  • 作図は既定で Mermaid、明示指示があるときのみ PlantUML
    • Mermaid はソースをそのままHTMLに書く
    • PlantUML は PNG を base64 で埋め込む
  • 印刷時は目次が消え、1カラムに切り替わる

2. 全体構成

2.1 処理フロー

図は <pre class="mermaid"> として本文中に直接記述する。

    D --> E[出力: 単一HTMLファイル]

3. 実装メモ

3.1 設定例

コードブロックは横スクロールし、等幅フォントで表示される。

{
  "output": "design-doc.html",
  "diagram": "mermaid",
  "embedImages": false
}

補足: インラインコード

ファイル名やクラス名は references/style.css のようにインラインコードで示す。

3.2 注意事項

WARN

Mermaid の CDN スクリプト以外の JavaScript を追加してはならない。外部CSS・外部フォントの読み込みも禁止する。

TIP

目次のリンク先は必ず本文の id と対応させる。ジャンプ先の位置は scroll-margin-top で調整済みなので、見出しが画面上端に貼り付くことはない。
