# ワークシートの規則

紙に印刷して手書きで記入する。回収しない。

## 列と行

- 列はスライドの Q1〜Q3 に合わせる。列見出しの文はデッキの問いと同じ文にする。デッキを生成した後に `index.html` から問いを読み、ワークシートと一致するか確かめる。
- Q3 が2つの問いを含む場合（例: 「組織に何が良い？ 部下に何を検討させる？」）は2列に分ける。spec では2列に同じ `group` を書くと、上段にまとめ見出し、下段に各列の見出しが入る。
- 回答例が「判断前の確認事項」を使う場合は、その列を残す（情報管理・権限・承認・費用）。
- 最後の列は「選んだ1件」（○を付ける）。build.py が自動で付ける。
- 行は `theme` を持つ `q` スライドごとに1行。行見出しには、テーマ名、例、スライドの Q1・Q2 の文が入る。

## 下段

- 自己点検: 回答例と書き直し（`adds`）に対応する項目を書く。例: 「指示が『誰に・何を・いつまでに』」「AIに任せる範囲と、確認する担当者を書いた」。
- 清書欄: 部下への検討指示を「誰に」「何を」「いつまでに」で書く（`fair` で変えられる）。

## spec の `worksheet`

| 項目 | 内容 |
|------|------|
| `title` | ワークシートの題 |
| `inst` | 題の下の手順（`<b>1</b>` で丸数字） |
| `cols[]` | `{"q": "Q1", "icon": "pin", "head": "列見出し", "small": "補足", "w": 16, "group": "まとめ見出し"}`。`w` は相対的な幅 |
| `row_w`, `pick_w` | 行見出しの列と「選んだ1件」の列の幅（既定 17、4.5） |
| `check[]` | 自己点検の項目 |
| `check_title`, `fair`, `fair_title` | 下段の見出しと清書欄の項目 |
| `footer` | 下の注記（例: 「研修内では導入承認を行わない。回収しない。」） |

## 印刷のための書式（worksheet.css）

- `@page { size: A4 landscape; margin: 8mm; }`。A4横1枚に収める。
- 列幅は % で指定する（build.py が `w` から計算する）。mm の固定幅にしない。
- `height` の固定と `overflow: hidden` を使わない。行の高さは `tbody tr { height: 36mm }`（表の行では最小の高さとして働く）だけにする。
- 記入欄は罫線（`td.w` の背景の線）で示す。
- アイコンは黒の線画にし、白黒印刷でも読めるようにする。見出しの灰色は `print-color-adjust: exact` で印刷する。
- テーマが4行以上で1枚に収まらない場合は、まずテーマ数を見直す。行の高さを下げる場合は worksheet.css の `tbody tr` の値を変える。
