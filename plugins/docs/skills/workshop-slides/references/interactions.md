## spec.json の形

```json
{
  "title": "ページのタイトル",
  "css": "デッキ固有の追加CSS（任意）",
  "slides": [ { "type": "cover", ... }, ... ],
  "worksheet": { ... }
}
```

- スライド番号 `n` は配列の位置で決まる（表紙が 0）。
- 文字列の項目はHTMLとしてそのまま埋め込む。`<b>` や `<span class="r-hu">` を使ってよい。
- `worksheet` は [worksheet.md](worksheet.md)。
- 動く例は `assets/example-spec.json`。

## スライドの型

### cover（表紙。先頭に1枚だけ）

| 項目 | 必須 | 内容 |
|------|------|------|
| `title` | 必須 | `h1` |
| `sub` | 任意 | 副題 |
| `il` | 任意 | 右上に置くイラスト名（2つまで） |
| `body` | 任意 | 副題の後ろに足すHTML（テーマの図など） |

### flow（部門課題＋Before / After。`split-a`）

| 項目 | 必須 | 内容 |
|------|------|------|
| `title`, `icon` | 必須 | 見出しとアイコン名 |
| `issue` | 必須 | `{"il": ["staff", "docs"], "text": "部門課題の一文", "tag": "部門課題"}` |
| `rows` | 必須 | 行の配列。行は `{"key": "before", "label": "Before", "sub": "導入前", "box_h": 130, "steps": [...]}` |
| `steps[]` | 必須 | `{"kind": "hu" \| "ai" \| "sys", "lines": ["1行目", "2行目"], "em": true, "tag": "出力①"}` |
| `aria` | 必須 | 図全体の説明文（読み上げ用） |
| `font`, `gap` | 任意 | 箱の文字サイズ（既定 26）と箱の間隔（既定 24）。1行の箱が多い時は小さくする |
| `stop` | 任意 | 文字列を渡すと、`em` の箱の上に停止の印とその文を置く（承認待ちの表現） |
| `after` | 任意 | 図の後ろに足すHTML |

`em: true` の箱は人間の確認として太枠になり、クリックで `hu` の強調を切り替える。行の見出し（Before / After）はクリックでその行を強調する。

### q（問いかけ・回答例。5分タイマー付き）

| 項目 | 必須 | 内容 |
|------|------|------|
| `title`, `icon` | 必須 | 見出しとアイコン名 |
| `qs` | 必須 | 問い3つ。ワークシートの行見出しにも同じ文が入る |
| `ans` | 必須 | 回答例 `[["見出し", "本文"], ...]`。最後の項目を緑で強調する |
| `bad`, `adds` | 必須 | 書き直しの悪い例と、書き足す項目（2つまで） |
| `closing` | 任意 | 最後に出す一文 |
| `theme` | 任意 | `{"label", "sub", "icon"}`。あるとワークシートの行になる |
| `times`, `qicons`, `sublead`, `timer` | 任意 | 問いごとの目安時間、問いのアイコン、上の注記、タイマー秒（既定 300） |

### html（自由なスライド）

| 項目 | 必須 | 内容 |
|------|------|------|
| `title`, `icon`, `body` | 必須 | 見出し、アイコン、本文のHTML |
| `cls` | 任意 | `split-b` など |
| `extra` | 任意 | 見出しの右に置くHTML |

## マークアップと JS の約束

`deck.js` と `shoot.mjs` は次の構造に依存する。`html` 型でも崩さない。

| 要素 | 役割 |
|------|------|
| `section.slide[data-n] > .stage > .inner` | 1スライド。`.stage` が 16:9 の舞台、`.inner` が中身 |
| `.slide.active` | 表示中のスライド |
| `.frag` / `.frag.shown` | 段階表示の単位 / 表示済み |
| `[data-hl="key1 key2"]` | 強調の対象。空白区切りで複数のキーを持てる |
| `[data-hl-btn="key"]` + `role="button"` + `tabindex="0"` + `aria-pressed` | 強調の切替。押すと `.slide[data-hl-on="key"]`、対象に `.lit`、他に `.dim` が付く |
| `.ans.frag` | 回答例。表示前はクリックで表示する枠になる |
| `button.timer[data-sec] > .tm` | 作業タイマー |
| `.fx-in` / `.fx-draw` / `.fx-pop` / `.fx-pulse` + `style="--d:.3s"` | 入場アニメーションと開始の遅れ |
| `#counter` / `#progress` | ページ番号と進捗バー |
| `#ah` | 矢印の marker（sprite.svg に含む） |

## 操作

| 操作 | 動作 |
|------|------|
| →、Space、PageDown、クリック | 次の段階。段階が無ければ次のスライド |
| ←、Shift+Space、PageUp | 前の段階。段階が無ければ前のスライド（全段階を表示した状態で入る） |
| 強調の要素をクリック、または Enter / Space | そのキーの強調を切り替える |
| Esc | 強調を解除する |
| 回答例の枠をクリック | 回答例まで段階を進める |
| タイマーをクリック | 開始と一時停止。0 で「時間です」。別のタイマーを開始すると動いている方は止まる |
| URL の `#5` | 5枚目を開く |
| URL の `?all` | 全スライドを全段階表示の状態にし、アニメーションを止める（確認と印刷用） |
